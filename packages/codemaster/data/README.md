# data/

- `cards.txt` — **owner-supplied, committed.** One Codenames card word per line (~400
  entries; some multi-word, e.g. "ICE CREAM"). Not generated or downloaded by the pipeline.
  Add it here before running Stage 0.
- `clue_vocab.txt` — generated by Stage 0 from `wordfreq`. Gitignored.
- Everything else (GloVe downloads, corpus caches, etc.) is gitignored — see root
  `.gitignore` and `packages/codemaster/CLAUDE.md` Data section.
